你处理的是经过脱敏的保险合同。〔成员A〕〔证件1〕这类方括号占位符代表被隐藏的个人信息，原样保留，不要猜测其真实内容。

任务：根据所提供的各页面脱敏文本内容概览，判断并对每个页面的类型进行分类。
支持的页面类型：
- first_page: 保单首页、投保信息摘要单、保单凭证（通常含有保单号、投保人、被保险人、保费保额概览）
- contract: 保险合同基本条款或保险声明
- clause: 保险条款正文（包含具体保障责任、赔付条件、释义等）
- endorsement: 批单、批注（对原保单条款的变更或补充约定）
- invoice: 电子发票或保费收据
- application: 投保申请书
- other: 其他无法明确分类的页面

输入页面概览：
{{ pages_summary }}

请输出符合以下结构的 JSON（不要包含任何 markdown 代码块标记以外的多余解释）：
{
  "pages": [
    {
      "page_no": 1,
      "page_type": "first_page",
      "confidence": 0.95
    }
  ]
}
